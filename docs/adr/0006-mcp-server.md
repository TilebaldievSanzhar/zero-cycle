# ADR 0006. MCP-сервер для агента: stdio, фоновые прогоны, находки в схеме ответа бенчмарка

> 28.10.2026 · Принято · PLAN, шаг 0.13 · Связано: [ADR 0005](0005-rule-engine.md),
> [PROTOCOL v0.2](../bench/PROTOCOL.md), [docs/mcp.md](../mcp.md)

## Контекст

Главная гипотеза бенчмарка — рука B против A1. Рука B — тот же агент, что A0 и A1, с теми же инструментами чтения
PDF, но с «Нулевым циклом» через MCP. Без сервера руки B нет. Ограничения:
- пакеты партнёров не покидают машину;
- агент видит только `package/`, а эталон лежит рядом;
- проверка большого пакета идёт минуты (Тауыш, 1 049 листов, — 181 с);
- все руки отвечают в одной JSON-схеме: категория, документ, страница, описание, основание.

## Решение

1. **Транспорт — stdio, процесс на машине пользователя.** SDK — `mcp` 1.x (FastMCP), как в second-key;
   верхняя граница `<2`: во второй версии FastMCP переименован. HTTP с токеном — на ступени 2, когда появится веб.
2. **Логика — в обычном классе `Session`, FastMCP — тонкая обёртка.** Инструменты тестируются без протокола;
   протокол — клиентом в памяти и одним запуском по stdio.
3. **Прогон — в фоне.** `check_package` запускает опись и правила в отдельном потоке и ждёт до `wait_seconds`
   (по умолчанию 50 с). Если не успел — возвращает `running`, агент зовёт `run_status`. Таймаут вызова у клиента
   не наступает, а движок не дробится на шаги ради протокола.
4. **Находка — в схеме ответа рук.** Поля `category`, `document`, `page`, `description`, `basis` и `id`, `status`,
   `severity`, `rule`. Агент переносит находку в ответ без перевода. Основание приходит из находки; инструкции
   сервера запрещают дописывать пункты норм.
5. **`--root` ограничивает пути.** Пакет вне корня — отказ. В бенчмарке корень — `package/`.
6. **Доказательство можно увидеть.** `render_fragment` рисует лист с рамкой якоря (pypdfium2 и Pillow) — это
   первая часть шага 0.9. `explain_finding` отдаёт карточку правила и то, как сверено основание.
7. **«Чего движок не проверяет» — часть ответа:**
   - `not_checked` и `rules_not_applicable` в сводке;
   - `scope` в `list_rules`;
   - `cannot_check` по каждой находке.

   Агент руки B должен знать, где проверять самому, — иначе сравнение с A1 нечестно.
8. **Внутри сервера модели нет.** Все вызовы модели делает агент. Стоимость руки B — это его токены плюс время
   движка.

## Почему

- stdio проще и безопаснее HTTP для локального агента: нет порта, токена и сетевой поверхности. Пакеты партнёров
  остаются у партнёра.
- Фоновый прогон вместо стриминга прогресса: клиенты по-разному обрабатывают уведомления о прогрессе, а повторный
  вызов `run_status` понимает любой агент.
- Схема ответа бенчмарка в находке убирает слой перевода, в котором агент мог бы исказить находку. Это тоже
  защищает сравнение рук.

## Последствия

- Команда `zerocycle mcp [--root] [--runs-dir]`, подключение — [docs/mcp.md](../mcp.md).
- Сессия держит прогоны в памяти, пока жив процесс; `--runs-dir` сохраняет отчёты.
- Распакованные zip живут до конца сессии, чтобы `render_fragment` мог открыть лист.
- Решения ГИПа по находкам, HTML-отчёт и HTTP-транспорт — позже (0.9, ступень 2).
