# План реализации: «Нулевой цикл»

> К стратегии [STRATEGY.md](STRATEGY.md). Статус на 26.10.2026.
> Правило распределения: **код идёт за данными.** До первого дизайн-партнёра — движок, CLI и бенчмарк;
> веб, очередь и роли переносим из `second-key`, когда появится пользователь, которому они нужны.
> Каждая ступень заканчивается измеримым критерием выхода.

## Ступень 0 — Фундамент и доказательство (недели 1–6)

**Цель:** движок формальных проверок на пакете правил РФ, засеянный корпус, бенчмарк против
«Claude Code + MCP» и 2–3 дизайн-партнёра.

**Критерий выхода:**
1. На отложенной части засеянного корпуса recall формальных дефектов ≥ 0,9, ноль выдуманных ссылок и чисел,
   детерминированные правила воспроизводимы в 5 прогонах из 5.
2. Бенчмарк v1 прогнан по протоколу, зафиксированному до прогона; отчёт опубликован.
3. Не меньше двух партнёров согласились дать прошлые пакеты с замечаниями.

**Сценарий разговора (F1), 20 минут:**
1. Сколько кругов замечаний обычно проходит пакет? Сколько это недель?
2. Какие замечания самые частые и самые обидные? Можно посмотреть одно письмо?
3. Кто делает нормоконтроль, сколько часов уходит на том? Чем пользуетесь?
4. Пробовали ИИ или скрипты для проверки? Что не получилось?
5. Дадите прошлый пакет с замечаниями (обезличенный) на бесплатную проверку?

## Ступень 1 — Ретро-пилот с партнёром (недели 6–12)

**Критерий выхода:** на 10 и более прошлых пакетах партнёров recall реальных замечаний в формальных категориях
выше руки A1; ложные тревоги приемлемы для ГИПа по слепой оценке; партнёр продолжает на текущих проектах.

- Разбор писем замечаний: замечание → категория, раздел, лист; сопоставление с находками.
- Пропущенные реальные замечания → новые правила и фикстуры; карточки — на рецензию практику.
- Пакет правил `kz`, если первый партнёр из Казахстана: СН РК 1.02-03, перечни Приказа 299, ТИМСО.

## Журнал

- **27.10.2026 (контекст пакета)** — юрисдикция, редакция СПДС и организация больше не зашиты в извлечении
  ([ADR 0003, дополнение 27.10](../adr/0003-jurisdiction-packs.md#дополнение-27102026)): `packs.context()` передаётся
  в разбор обозначений, поиск основной надписи и опись явно (`-j ru|kz`, `--org`); профиль штампа — по редакциям СПДС
  (`2020`, `97` — без сверки); шифры РК (ОПЗ, СС, СД …) — `packs/kz/sections.toml`; слой организации — TOML поверх.
  Проверка против прежнего кода: засеянный корпус (327 листов) — опись совпала полностью; 2 135 реальных листов РК —
  отличается один (подпись «Формаm» в графе 26 теперь отбрасывается), в контексте `kz` два документа получили шифры
  РК, у 12 сняты номера разделов ПП 87. Это же сравнение поймало ошибку переноса, которую тесты не видели. 141 тест.
- **27.10.2026 (протокол бенчмарка v0.2)** — главная гипотеза — рука B (агент + «Нулевой цикл» через MCP) против
  A1 (агент + скилы по публичным правилам), с порогами и решениями по исходу. Пакеты из закупок РК — версии после
  экспертизы, поэтому recall реальных замечаний на них не измерить; добавлен слой RS — формальные дефекты, засеянные
  в полные реальные пакеты с частотами 893 пунктов замечаний. Без пакета `kz` засев покрывает типы 33% формальных
  пунктов, с `kz`-минимумом — 80%: ещё один довод за 0.7k. До заморозки — пилот на 3–5 пакетах для бюджета.
- **26.10.2026 (замечания РК, 0.11b)** — 150 завершённых закупок СМР; у 74 есть заключения экспертизы. Из
  72 заключений по ПСД подраздел «Дополнения и изменения» с пунктами — у 49. У РГП «Госэкспертиза» такого
  подраздела в форме нет, поэтому замер — по частным экспертизам ([REMARKS_KZ.md](../bench/REMARKS_KZ.md)).
  Модуль `remarks/`:
  - разбор подраздела: колонтитулы, четыре варианта заголовка, группы по разделам, пункты всех видов нумерации;
  - кодбук из 9 категорий;
  - замер с бутстрепом по заключениям и копиями списков, учтёнными один раз.

  Все 893 пункта размечены вручную, правила совпали с разметкой в 69% случаев. **H1 подтверждена:**
  формальные — 62% [57–67%], в самом осторожном варианте — 51% (порог 25%). Чаще всего встречаются:
  - не хватало ИРД и согласований — в 27 заключениях из 49;
  - не хватало расчётов — в 18;
  - сведения в ПЗ, листы и документы сметы — по 20;
  - общие данные и ведомости — в 19;
  - основная надпись и подписи — в 14.

  Что узнали по дороге:
  - В РК эксперты ссылаются на ГОСТ 21.101-97, а не на ГОСТ Р 21.101-2020. Слою `spds` нужна редакция
    стандарта как измерение ([ADR 0003](../adr/0003-jurisdiction-packs.md#дополнение-26102026)).
  - Ссылки на нормы в РК сверяют с перечнем АГСК-1, коды в спецификациях — с классификатором АГСК-3.
  - Эксперты переносят списки изменений из заключения в заключение почти дословно: найдено 4 копии.
  - Прикидка «14 из 25» в REAL_KZ была неверной: у Талапа 54 пункта, а не 7.
  - 70 тестов разбора и кодбука, всего 127.
- **23.10.2026 (реальные пакеты)** — 0.11, первая итерация: 4 закупки СМР с goszakup.gov.kz, 39 файлов, 921 лист
  ([REAL_KZ.md](../bench/REAL_KZ.md)). Опись по геометрии ГОСТ на реальных листах не держится: поля, строки,
  колонки, штампы ЕСКД, таблицы Word с двойными границами, штамп в середине листа. Новый способ «grid» — от шапки
  «Изм. … Дата» по фактическим линиям: штамп найден на 368 из 600 листов ПСД с текстом (было 277), пять
  вариантов — в регрессионных тестах; 57 тестов. 21% листов без текстового слоя (сканы и текст САПР в кривых) —
  нужен OCR. Уже по штампам видны дефекты прошедших экспертизу пакетов: чужое место строительства в штампах
  привязанного типового проекта, нет базового обозначения, стадия «ЭП» в рабочем проекте. Главная находка:
  в заключениях экспертизы РК есть раздел «Дополнения и изменения, внесённые в процессе экспертизы» — открытый
  корпус замечаний без партнёра; прикидка на двух заключениях — 14 из 25 пунктов про комплектность
  и оформление.
- **23.10.2026 (код)** — шаги 0.2–0.4. Опись пакета на засеянном корпусе (5 пакетов, 414 листов): основная надпись
  найдена на всех 329 листах, где она есть, и ни на одном из 85 титульных листов; форма определена верно везде;
  2 404 из 2 404 граф и 329 из 329 таблиц подписей прочитаны точно; опись — около 2 с на пакет, генерация — 0,4 с.
  Чтение без линий (штамп «напечатан» текстом) работает по подписям граф. 45 тестов.
  Что узнали по дороге:
  - Реестр «Стройкомплекс.РФ» содержит только обязательные требования: ГОСТ Р 21.101-2020 (СПДС) в нём нет —
    это добровольный стандарт. Правило ссылок (0.7) не должно считать «нет в реестре» дефектом; заменённые
    добровольные стандарты (ГОСТ Р 21.1101-2013) ловятся только курируемой таблицей замен — дефект D07R.
  - Свежие замены редакций — реальная ловушка для проектировщика: СП 6.13130.2021 → 2025, СП 3.13130.2009 → 2026,
    СП 131.13330.2020 → 2025. В корпусе они есть.
  - Шифры прил. Б ГОСТ отстают от ПП 87 — раздел определяется по номеру и наименованию.
  - На Windows со Smart App Control .exe-обёртку команды блокирует политика: запуск — `python -m zerocycle`.
- **23.10.2026** — основан репозиторий. Решения владельца: трек BI Group не якорь; консультант — по бартеру,
  платно позже; оба продукта параллельно; Россия — источник данных и первый пакет правил на общем фундаменте;
  юрлицо — позже. Рабочее название — «Нулевой цикл».
