# Имя файла документа ПДЭ начинается с его обозначения

`spds.pde.file-names` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| формат подачи | оформление | мелочь | юрисдикция: ru |

**Почему эксперт это ловит.** Имя файла ПДЭ составляют из обозначения документа, номера листа и наименования (8.2.6): по нему документ находят в пакете без info.xml. «ПЗ1_финал.pdf» не говорит, какой это документ и какая версия.

**Как это пишет эксперт.** Переименовать файл {файл} по обозначению документа: «{обозначение}».

**Основание.**
- ГОСТ Р 21.101-2020, 8.2.6

**Как сверено основание.**
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F06 — имя файла не по обозначению

**Фикстуры.**
- по обозначению → норма — 1, нарушено — 0
- имя не по обозначению → нарушено — 1; 01/ПЗ1_финал.pdf: нарушено
- «/» в обозначении: «_» в имени — верно, папка — нет → нарушено — 1, норма — 1; «/» в обозначении: нарушено
- нет info.xml → проверить невозможно — 1
