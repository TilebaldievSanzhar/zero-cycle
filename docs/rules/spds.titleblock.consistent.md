# На всех листах документа — его обозначение

`spds.titleblock.consistent` · версия 0.2.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | согласованность | существенно | везде |

**Почему эксперт это ловит.** Лист с чужим обозначением — лист другого документа или объекта: при изменениях и замене листов его не найдут, а эксперт считает документ некомплектным.

**Как это пишет эксперт.** На листе {лист} документа {документ} в графе 1 указать «{стало}» вместо «{было}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 1)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 1)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: D03 — неверное обозначение в графе 1 (цифры, шифр, хвост)

**Фикстуры.**
- одно обозначение → норма — 1
- переставлены цифры базовой части → нарушено — 1; ПЗ.pdf:2: нарушено
- первый лист без хвоста документа → нарушено — 1; ПЗ.pdf:1: нарушено
- часть из двух листов: на втором снят хвост → нарушено — 1; ПЗ.pdf:2: нарушено
- часть из двух листов: на первом снят хвост → нарушено — 1; ПЗ.pdf:1: нарушено
- чужой шифр — не обозначение этого документа → нарушено — 1
- содержание и части тома — свои обозначения → нарушено — 0, норма — 1
- нет обозначений → проверить невозможно — 1
