# Ссылки на нормы — на действующие редакции по реестру «Стройкомплекс.РФ»

`ru.norms.registry` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| нормы и ссылки на них | ссылка | существенно | юрисдикция: ru |

**Почему эксперт это ловит.** С 01.03.2026 экспертиза проверяет требования по реестру «Стройкомплекс.РФ»: ссылка на прежнюю редакцию свода правил или на СНиП, который актуализирован сводом правил, — замечание «актуализировать ссылки».

**Как это пишет эксперт.** Заменить ссылку на {было} действующим {стало}.

**Основание.**
- Реестр «Стройкомплекс.РФ»

**Как сверено основание.**
- Реестр «Стройкомплекс.РФ»: индекс собран из выгрузки открытого API: src/zerocycle/packs/ru/stroykompleks.json (scripts/stroykompleks_index.py, bim-data/datasets/stroykompleks/ntd_documents.json)

**Откуда знаем, что это ловят.**
- Реестр «Стройкомплекс.РФ», 21.10.2026: 9 сводов правил со свежей заменой редакции (СП 6.13130.2021 → 2025, СП 3.13130.2009 → 2026, СП 131.13330.2020 → 2025), 106 актуализированных СНиП в наименованиях сводов правил
- Каталог дефектов засеянного корпуса: D07 — устаревшая редакция по реестру; D07R — заменённый добровольный стандарт вне реестра (ГОСТ Р 21.1101-2013)

**Фикстуры.**
- прежняя редакция СП → нарушено — 1, норма — 0
- актуализированный СНиП → нарушено — 1
- заменённый стандарт СПДС → нарушено — 1
- действующие редакции → норма — 1, нарушено — 0, проверить вручную — 0
- новая редакция ещё не вступила на дату подачи → проверить вручную — 1, нарушено — 0
- нет в реестре обязательных требований → проверить невозможно — 1, проверить вручную — 0, нарушено — 0
- ссылка новее реестра → проверить вручную — 1
- нет текста → проверить невозможно — 1
