# «Листов» на первом листе равно числу листов документа

`spds.sheets.count` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | оформление | мелочь | везде |

**Почему эксперт это ловит.** Графа 8 — общее количество листов документа: по ней проверяют, что документ пришёл целиком. Расхождение значит, что лист потерян, лишний или графа не обновлена после изменения.

**Как это пишет эксперт.** В графе 8 первого листа документа {документ} указать {листов} — по числу листов.

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 8)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 8)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F02 — «Листов» не равно числу листов документа

**Фикстуры.**
- совпадает → норма — 1
- меньше листов → нарушено — 1, норма — 0
- титул в общем счёте: последний лист — 3 → нарушено — 0, норма — 1
- документ в двух файлах → нарушено — 0, норма — 1
- лист с чужим обозначением посреди документа — не другой документ → нарушено — 0, норма — 1
- последний лист с чужим обозначением, нумерация продолжается → нарушено — 0, норма — 1
- «Листов» на каждом листе (шаблон РК) и добавленный лист «3.1» → нарушено — 0, норма — 1
- «Листов» на каждом листе, лист с нечитаемым номером посередине → нарушено — 0, норма — 1
- последние листы без читаемой основной надписи → нарушено — 0, норма — 1
- нет графы 8 → проверить невозможно — 1
