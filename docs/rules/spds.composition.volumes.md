# «Состав проектной документации» и тома пакета совпадают

`spds.composition.volumes` · версия 0.2.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| комплектность | согласованность | существенно | везде |

**Почему эксперт это ловит.** Эксперт принимает пакет по ведомости «Состав проектной документации»: том из ведомости, которого нет, — некомплект; том, которого нет в ведомости, — неучтённый документ.

**Как это пишет эксперт.** Привести в соответствие «Состав проектной документации» и тома: {том}.

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Р (форма 16)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, 8.1.6, прил. Т

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F09 — том из «Состава ПД» отсутствует; F05 — том не указан в «Составе ПД»

**Фикстуры.**
- совпадают → норма — 1
- тома из ведомости нет в пакете → нарушено — 1; указан, нет в пакете: 2345-ИОС1: нарушено
- тома нет в ведомости → нарушено — 1; нет в составе: 2345-ОДИ: нарушено
- книги тома записаны томом → нарушено — 0, норма — 1
- «не разрабатывается» — тома и нет → нарушено — 0, норма — 1
- «не разрабатывается», а том есть → нарушено — 1; не разрабатывается, но есть: 2345-СМ: нарушено
- нет ведомости → проверить невозможно — 1
