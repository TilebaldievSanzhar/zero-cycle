# У каждого документа ПДЭ свой GUID

`spds.pde.guid` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| формат подачи | оформление | существенно | юрисдикция: ru |

**Почему эксперт это ловит.** По GUID система экспертизы отличает документы и их версии при повторной подаче: два документа с одним GUID — один из них потеряется или заменит другой.

**Как это пишет эксперт.** Назначить документам {документы} разные GUID в info.xml.

**Основание.**
- ГОСТ Р 21.101-2020, 8.2.4

**Как сверено основание.**
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F07 — повтор GUID в info.xml

**Фикстуры.**
- разные → норма — 1
- повтор → нарушено — 1, норма — 0
- нет info.xml → проверить невозможно — 1
