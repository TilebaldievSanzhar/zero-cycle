# Наименование объекта в основных надписях — одно и то, что заявлено в ОПЗ

`core.object-name.consistent` · версия 0.2.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| увязка | согласованность | существенно | везде |

**Почему эксперт это ловит.** Наименование объекта — одно на весь проект. Чужое наименование в штампе — след привязки типового проекта или копирования из другого объекта; эксперт пишет «название объекта в штампах откорректировать согласно АПЗ».

**Как это пишет эксперт.** Наименование объекта в основных надписях листов {листы} не соответствует наименованию проекта: «{было}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 2)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 2)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- REMARKS_KZ: «Название объекта в штампах … откорректировано согласно АПЗ и задания» (4 пункта, 3 заключения)
- REAL_KZ: пакет Тауыш прошёл экспертизу с местом строительства «село Кына» в штампах АР, ВК, ОВ, ПБ

**Фикстуры.**
- одно наименование, разная запись → норма — 1, нарушено — 0
- чужое место строительства → нарушено — 1, норма — 0
- все штампы — от типового проекта, в ОПЗ — свой объект → нарушено — 1, норма — 0
- наименование в графе 1 вместо обозначения → нарушено — 1
- нет основных надписей → проверить невозможно — 1
