# В строках подписей основной надписи у каждой роли есть фамилия и дата

`spds.titleblock.signatures` · версия 0.2.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | оформление | существенно | везде |

**Почему эксперт это ловит.** Строка подписи без фамилии — документ без ответственного: эксперт возвращает с замечанием «поставить подписи и фамилии исполнителей и ГИПа». Дата подписания — графа 13; если даты в штампе пишут, строка без даты — подпись, которую не поставили.

**Как это пишет эксперт.** В основной надписи листов {листы} указать фамилию и дату в строке «{роль}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графы 10–11)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графы 10–11)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- REAL_KZ: пакет Тауыш — в книге ПБ у «ГИП» и «Выполнил» нет фамилий
- REMARKS_KZ: основная надпись, подписи, титульные листы — 37 пунктов в 14 заключениях из 49

**Фикстуры.**
- фамилии на месте → норма — 1
- ГИП без фамилии → нарушено — 1, норма — 0
- нет строк подписей → проверить невозможно — 1
- роль не читается — не судим → нарушено — 1; ПБ.pdf:Н контроль: нарушено
- нет даты, у остальных строк есть → нарушено — 1; ПБ.pdf:Разраб:дата: нарушено
- даты не пишут во всём штампе — не судим → нарушено — 0, норма — 1
