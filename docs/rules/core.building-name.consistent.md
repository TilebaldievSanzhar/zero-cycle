# Наименование здания в графе 3 одно во всех томах

`core.building-name.consistent` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| увязка | согласованность | существенно | везде |

**Почему эксперт это ловит.** Том с другим номером дома или корпуса в графе 3 — том от соседнего объекта или не исправленная копия: эксперт не может принять, что решения тома относятся к этому зданию.

**Как это пишет эксперт.** В основной надписи тома {том} указать наименование здания «{стало}» вместо «{было}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 3)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 3)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F04 — наименование здания в томе отличается

**Фикстуры.**
- одно → норма — 1
- другой номер дома в одном томе → нарушено — 1; ОВ.pdf: нарушено
- приписан корпус → нарушено — 1
- та же запись без сокращения — проверить → нарушено — 0, проверить вручную — 1
- другое здание того же пакета — не ошибка → нарушено — 0, норма — 1
- нет графы 3 → проверить невозможно — 1
