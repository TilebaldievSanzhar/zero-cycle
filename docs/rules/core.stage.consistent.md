# Стадия одна во всём документе и пакете

`core.stage.consistent` · версия 0.2.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | согласованность | мелочь | везде |

**Почему эксперт это ловит.** Стадия в графе 6 — одна для всех листов документа; лист с другой стадией пришёл из другого комплекта и, значит, мог не пройти корректировку вместе с остальными.

**Как это пишет эксперт.** На листе {лист} указана стадия «{было}», на остальных листах документа — «{стало}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 6)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 6)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- REAL_KZ: пакет Байгабыл — стадия «ЭП» на листе ВК рабочего проекта, на остальных — «РП»

**Фикстуры.**
- одна стадия → норма — 1
- чужая стадия на листе → нарушено — 1
- поровну листов в документе — чужая та, что не как у пакета → нарушено — 1, проверить вручную — 0; ТБЭ.pdf:Р: нарушено
- эскизный проект целиком — не ошибка → норма — 1, нарушено — 0, проверить вручную — 0
- нечитаемая стадия — не судим → норма — 1, нарушено — 0
- документ целиком в другой стадии → проверить вручную — 1, нарушено — 0
