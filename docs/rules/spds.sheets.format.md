# Формат, записанный у основной надписи, совпадает с размером листа

`spds.sheets.format` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | оформление | мелочь | везде |

**Почему эксперт это ловит.** По графе 26 печатают и проверяют масштаб: для электронного документа указывают формат, на котором изображение соответствует масштабу. Если лист другого размера, масштаб чертежа не тот, что подписан.

**Как это пишет эксперт.** На листе {лист} документа {документ} формат в графе 26 «{было}» не совпадает с размером листа {стало}.

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (формат листа)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 26)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F08 — формат в графе 26 не совпадает с размером листа

**Фикстуры.**
- совпадает → норма — 1
- лист больше записанного → нарушено — 1
- печать с уменьшением: штамп тоже уменьшен → нарушено — 0, норма — 1
- нестандартный штамп и чужой формат — проверить → нарушено — 0, проверить вручную — 1
- формат не записан → проверить невозможно — 1
