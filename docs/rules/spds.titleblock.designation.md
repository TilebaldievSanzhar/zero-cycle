# В графе 1 основной надписи — обозначение документа без ошибок записи

`spds.titleblock.designation` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | оформление | мелочь | везде |

**Почему эксперт это ловит.** По обозначению документ находят в составе проекта, в ссылках и в изменениях. Обозначение без базовой части («-ОВ») или наименование объекта вместо обозначения не позволяют отличить документы разных объектов.

**Как это пишет эксперт.** В графе 1 основной надписи листов {листы} указать обозначение документа: «{было}».

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 1)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 1)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- REAL_KZ: пакет Байгабыл — ни на одном листе нет базового обозначения («-ОВ», «-АС»); в ОПЗ двух пакетов в графе 1 — наименование объекта
- REMARKS_KZ: «в графе 1 указаны обозначение документа согласно п. 4.1.3 ГОСТ 21.101-97»

**Фикстуры.**
- обозначение на месте → норма — 1, нарушено — 0
- нет базового обозначения → нарушено — 1
- наименование вместо обозначения на одном листе → нарушено — 1, норма — 1
- тире вместо дефиса → нарушено — 1
- шифр среди текста заказчика → нарушено — 1; ОВ.pdf:Заказчик: ГУ "Управление строительства" ВК градостроительства: нарушено
- нечитаемый шрифт и обрывок «№» — не судим → норма — 1, нарушено — 0
- отчёт изысканий со своим штампом — не документ проекта → проверить невозможно — 1, нарушено — 0
- нет основных надписей → проверить невозможно — 1
