# Листы документа пронумерованы подряд, без пропусков и повторов

`spds.sheets.numbering` · версия 0.1.0 · черновик — не проверено практиком

| Семейство | Вид проверки | Тяжесть | Применимость |
|---|---|---|---|
| оформление | оформление | мелочь | везде |

**Почему эксперт это ловит.** Пропуск в нумерации — признак потерянного или выброшенного листа: эксперт сверяет листы с ведомостью и возвращает документ «доукомплектовать». Аннулированный лист номер не освобождает (7.3.9), но такой лист видно по таблице изменений.

**Как это пишет эксперт.** Проверить комплектность и нумерацию листов документа {документ}: после листа {лист} — лист {следующий}.

**Основание.**
- ГОСТ 21.101-97: ГОСТ 21.101-97, прил. Д (графа 7)
- ГОСТ Р 21.101-2020: ГОСТ Р 21.101-2020, прил. Ж (графа 7)

**Как сверено основание.**
- ГОСТ 21.101-97: не по тексту стандарта: по ссылкам экспертов РК в 14 заключениях из 49 (docs/bench/REMARKS_KZ.md) — основные надписи по приложению Д, обложка и титульный лист — по приложениям Н и П, состав проекта — по форме 16 приложения Р
- ГОСТ Р 21.101-2020: по тексту стандарта: bim-data/norms/ru/GOST_R_21.101-2020_SPDS_osnovnye_trebovaniya.pdf

**Откуда знаем, что это ловят.**
- Каталог дефектов засеянного корпуса: F01 — пропуск в нумерации листов; D02 — лист выброшен, а номер остался
- REMARKS_KZ: листы — нумерация, ведомости, «Листов» — среди частых формальных пунктов

**Фикстуры.**
- подряд → норма — 1
- пропуск номера → нарушено — 1, норма — 0
- страница без штампа между листами — не пропуск → нарушено — 0, норма — 1
- новый документ в том же файле начинается с 1 → нарушено — 0, норма — 1
- повтор номера → проверить вручную — 1, нарушено — 0
- нет номеров листов → проверить невозможно — 1
