# Скил для проверки ПСД Республики Казахстан

`kz-rp-review` ведёт офлайн-проверку стадии «РП»: комплектность по применимым приложениям 2, 3, 4, 4-1, 5 к приказу № 299; оформление по предоставленному ГОСТ 21.101-97; увязка томов, названий и ТЭП; нормативные ссылки по АГСК-1 за июнь 2025. Замечания отделены от ограничений и требуют доказательств из пакета и точного нормативного основания.

Скопируйте **папку `kz-rp-review` целиком** в `.agents/skills/` папки прогона. Получится `.agents/skills/kz-rp-review/SKILL.md`. Пакет положите в `package/` той же папки и дайте агенту исходную задачу. Скил выбирается Codex по `description`, его также можно вызвать явно как `$kz-rp-review`.

Внутри: инструкции, полные локальные тексты/выписки из выданных источников, рисунки форм, PDF АГСК и его постраничный поисковый индекс; скрипты извлечения PDF/Excel/Word/изображений, поиска, рендеринга страниц и проверки структуры JSON-отчёта. Всё работает через `python` в PowerShell без интернета и установки зависимостей. Исходная папка `sources/` для прогона не нужна; промежуточные файлы создаются в `review_work/`.

Скрипты не устанавливают нарушения автоматически. Сканы и подписи требуют просмотра; Word/Excel не получают вымышленных номеров PDF-страниц. Тексты СН РК 1.02-03-2022 и п. 15 Правил отсутствуют; ГОСТ/СТ РК не входят в охват АГСК-1, сметные нормы вынесены в АГСК-5, а актуальность после июня 2025 не подтверждается.

Проверка скриптов выполнена на искусственно созданных PDF (включая скан и поворот), Excel с формулами/кешем и скрытым листом, Word с таблицей/колонтитулом/рисунком и растровых изображениях. Тестовые материалы и протокол находятся **вне поставки**, в `workbench/`; их копировать в скилы не нужно.
