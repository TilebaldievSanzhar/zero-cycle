# Комплектность: применимость и точные основания

Ниже карта навигации, а не замена полных текстов приложений. Перед замечанием перечитай нужный пункт в `order_299_appendix_*.txt`, включая условия и исключения. «Исключён» не означает, что документ надо требовать. Наименование файла не подтверждает его содержание/утверждение.

## Выбор перечня

| Подтверждённый вид подачи | Основа |
|---|---|
| Новое строительство | Приложение 2 |
| Реконструкция, расширение, модернизация, техническое перевооружение существующего объекта | Приложение 3 |
| Капитальный ремонт | Приложение 4 |
| Увеличение ранее утверждённой сметной стоимости не менее чем на 10% из-за стоимости строительных ресурсов, обращение подрядчика, без изменения проектных решений | Приложение 4-1. Не применять к любой корректировке сметы. |

Стадия «РП» сама не выбирает приложение. Финансирование, изменение фасадов, новые подключения, уникальность, стадия строительства и особые условия должны быть подтверждены файлами. Если их невозможно установить, зафиксируй неопределённость, не делай все условные требования обязательными.

## Приложение 4-1 — специальная корректировка сметной стоимости

Условия из заголовка/вводного абзаца: ранее утверждённая ПСД, рост стоимости не менее 10% по причине стоимости ресурсов, обращение подрядчика, отсутствие изменений проектных решений. Не переносить этот порог на иные проверки стоимости или расхождений ТЭП.

| Подпункт перечня | Требование |
|---|---|
| 1) | Письмо-обращение подрядчика о пересмотре сметы без изменения проектных решений. |
| 2) | Задание на корректировку сметной документации без изменения проектных/технических решений. |
| 3) | Для бюджетных и иных государственных инвестиционных проектов — решение бюджетной комиссии и аудиторский отчёт уполномоченного органа внутреннего государственного аудита. **Для капремонта аудиторский отчёт не требуется**; исключение не отменяет автоматически требование решения комиссии. |
| 4) | При иных средствах — документ о дополнительном финансировании, ориентировочная/предельная сумма удорожания, подпись первого руководителя или уполномоченного лица. |
| 5) | Разделительная ведомость выполненных/остаточных физических объёмов, утверждённая заказчиком и согласованная техническим/авторским надзорами. |
| 6) | Сметы выполненных работ в ценах ранее положительного заключения. |
| 7) | Сметы остаточных объёмов в текущих ценах. |
| 8) | Ранее выданное заключение комплексной экспертизы и ранее одобренная сметная документация. |

В этом приложении перечень непосредственно нумерован `1)` … `8)`, не добавляй фиктивный `п. 1`.

## Разделы РП, расчёты и сметы

ГОСТ 3.1 отсылает к строительным нормам. ГОСТ 3.2 перечисляет состав рабочей документации **в общем случае**, включая рабочие чертежи, документацию изделий, необходимые эскизы нетиповых изделий, спецификации, другую прилагаемую и сметную документацию по установленным формам. Это не полный перечень разделов РП по СН РК 1.02-03-2022.

Проверь реальное наличие расчётов, изысканий, смет, перечней, названных в задании/ведомостях. Обязательность каждого конкретного раздела/расчёта не выводи из строительного опыта. Нет точной доступной нормы — зафиксируй предел проверки или подтверждённое расхождение состава в summary, не сочиняй основание. Не требуй выдачи всех ссылочных нормативов внутри пакета: ГОСТ 4.2.7 различает ссылочные и прилагаемые документы и допускает выдачу ссылочных только по отдельному договору.
