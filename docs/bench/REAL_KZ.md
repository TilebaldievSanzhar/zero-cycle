> Сбор — `scripts/goszakup_kz_psd.py`, файлы — в `var/real/goszakup_kz/` (вне git: документы третьих лиц

## Что взяли

Четыре завершённые закупки СМР дороже 150 млн ₸, у каждой — срез по разделам (заключение экспертизы, ОПЗ,
паспорт, АР, АС/КЖ, ОВ, ВК, ЭОМ, ГП, ПОС): 39 файлов, 91 МБ, 921 лист. Полные пакеты — 13–58 файлов;
файловый сервер отдаёт около 50 КБ/с на поток, поэтому только срез.

## Основные надписи: что нашлось

Первая версия описи (геометрия ГОСТ у угла рамки) нашла штамп на 277 листах. После переделки — на 368 из 600
листов ПСД с текстом: по сетке от шапки — 296, по геометрии ГОСТ — 70, по подписям граф — 2; плюс рамка на
60 листах без текста. Остальные листы с текстом без штампа — в основном приложения ИРД внутри ОПЗ и титулы.
Точной полноты пока нет: для неё нужна разметка «на каком листе есть штамп» — следующая итерация.

Чем реальные штампы отличаются от ГОСТ Р 21.101-2020 (каждый вариант теперь в регрессионных тестах
`tests/test_titleblock_variants.py`, нарисованный синтетически):

- поля рамки и размеры другие: строки 4,4–6,8 мм вместо 5, колонки 9,6–12,5 мм, форма 6 растянута на 251 мм;
- штамп ЕСКД (ГОСТ 2.104, форма 2а): «Изм | Лист | № докум. | Подп. | Дата» без «Кол.уч», внизу «Копировал»;
- таблицы Word: у каждой ячейки своя рамка с зазором 0,5 мм — каждая граница двойная;
- шапка верхней строкой без линии над ней; «Код» вместо «Кол.уч»; «Nдок», «Подпись»;
- штамп в теле Word-документа над колонтитулом, а не у угла листа;
- лист с уменьшением вписан в чужой формат: рамка и штамп в середине страницы А2;
- таблица нагрузок стоит вплотную на основной надписи;
- шрифты САПР: «Формаm АЗ» — латинская m и буква З вместо цифры 3.

Вывод осторожный: раз такие пакеты проходят экспертизу РК, формальные дефекты штампов сами по себе там
не главная причина замечаний. Их ценность — в увязке (чужое место строительства в штампах — уже не формальность)
и в нормоконтроле, а для России, где нормоконтроль по ГОСТ Р 21.101 строже, — выше.

## Замечания экспертизы лежат в открытом доступе

В каждом из четырёх заключений есть раздел «Дополнения и изменения, внесённые в рабочий проект в процессе
экспертизы» (номер 7.1 или 7.2): что проектировщик исправил по замечаниям, по разделам. Подробность разная:
- у Тауыша 20 пунктов;
- у Талапа 54 пункта на трёх страницах;
- у Атырау 2 пункта по смете и таблица ТЭП «до/после» (общая площадь 1 289,68 → 1 201,23 м²);
- у Байгабыла одна строка.

Заключения частных экспертиз формируются в информационной системе Палаты экспертных организаций — возможный
источник сверх закупок.

Что это значит для продукта: корпус «пакет → замечания» для Казахстана собирается без партнёра — из заключений,
приложенных к закупкам. Замер на 49 заключениях — [REMARKS_KZ](REMARKS_KZ.md): формальные — 62% пунктов
(95% интервал 57–67%). Первая прикидка здесь, «14 из 25 пунктов», была неверной: у Талапа подраздел занимает
три страницы, а не одну, и пунктов в нём 54, а не 7.

## Портал сменился — 11.11.2026

- **`goszakup.gov.kz` теперь перенаправляет на `zakup.gov.kz`** — «Единую платформу закупок»: госзакупки, квазигоссектор
  и «Самрук-Казына» в одной системе. Старый портал `old.goszakup.gov.kz`, по которому работает
  `scripts/goszakup_kz_psd.py`, и файловый сервер `v3bl.goszakup.gov.kz` отвечают урывками. С вечера 09.11 не было
  соединения, кроме короткого окна около полуночи 10.11; 11.11 в 14:53 оба снова ответили, и сбор пошёл.
- **У новой платформы есть открытое REST API** (`/api/core/api/public/…`):
  - `announcements/` — 14,3 млн объявлений. Фильтры: `purchase_subject_id=2` — работы, `total_price__gte`, `q` — текст,
    `ordering`, `announcement_number` (номер старого портала с суффиксом `-1`). Неизвестный параметр API отклоняет
    с понятной ошибкой;
  - `announcements/{id}/general-files/`, `/lots/` — группы файлов и лоты.
- **Но файлов ПСД в открытом API нет.** В группах — типовые документы: конкурсная документация, сгенерированная
  техническая спецификация, лицензии. Группа «Дополнительные файлы для тех. спецификации» пуста даже у real-1, к
  которому на старом портале было приложено около 20 томов. Ссылки на файлы по-прежнему ведут на `v3bl.goszakup.gov.kz`.

Что это значит: пакеты РК качаются, только когда отвечают старые сервера. Фоновое наблюдение раз в 15 минут
проверяет оба адреса и запускает сбор, когда они отвечают. Если старый портал закроют совсем, список объявлений
можно брать из API новой платформы, но сами файлы ПСД через открытое API не найдены.
