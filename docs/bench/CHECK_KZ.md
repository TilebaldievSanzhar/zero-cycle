# Первые правила на реальном слое РК: два пакета ФАП

> 28.10.2026 · PLAN, шаги 0.5 и 0.7k. Движок правил ([ADR 0005](../adr/0005-rule-engine.md)) и шесть правил
> цепочки `core` → `spds` → `kz` прогнаны на двух полных пакетах ПСД из закупок РК. Оба пакета прошли
> экспертизу и получили положительные заключения. Карточки правил — [`docs/rules/`](../rules/).

## Что проверяли

Два фельдшерско-акушерских пункта (ФАП), новое строительство, рабочий проект:

| Пакет | Файлов PDF | Листов | С основной надписью | Без текстового слоя | Что внутри |
|---|---|---|---|---|---|
| Тауыш (закупка 17778737) | 41 | 1 049 | 180 | 174 | привязка типовых проектов, ИРД, изыскания, смета, заключение |
| Байгабыл (закупка 17773093) | 37 | 703 | 166 | 43 | ПСД, ИРД, изыскания, эскизный проект, смета, заключение |

Правила:

| Правило | Что проверяет | Основание |
|---|---|---|
| `core.object-name.consistent` | наименование объекта в основных надписях одно и совпадает с заявленным в ОПЗ | ГОСТ 21.101-97, прил. Д (графа 2) |
| `core.stage.consistent` | стадия одна в документе и пакете; эскизный проект — своя стадия | ГОСТ 21.101-97, прил. Д (графа 6) |
| `spds.titleblock.designation` | в графе 1 — обозначение с базовой частью, без ошибок записи | ГОСТ 21.101-97, прил. Д (графа 1) |
| `spds.titleblock.signatures` | в строках подписей у каждой роли есть фамилия | ГОСТ 21.101-97, прил. Д (графы 10–11) |
| `kz.completeness.ird` | ИРД и сопроводительные документы для экспертизы | Правила КВЭ (Приказ № 299), прил. 2–4 |
| `kz.norms.agsk1` | ссылки на нормы — на действующие редакции | АГСК-1 (июнь 2025), с указанием страницы |

## Что найдено в пакетах, которые прошли экспертизу

1. **Тауыш: чужое место строительства в 36 штампах.** В основных надписях АР, ОВ, ВК, АС и книги ПБ —
   «Строительство фельдшерско-акушерского пункта в селе Кына, Аккольского района, Акмолинской области».
   В ОПЗ — «…в селе Тауыш Джангельдинского района» (привязка). Альбомы типового проекта переложены без правки
   штампов. Этот дефект в [REAL_KZ](REAL_KZ.md) нашли вручную, теперь он находится автоматически.
2. **Тауыш: 14 ссылок на заменённые нормы**, у каждой — лист в пакете и страница АГСК-1:
   - СП РК 2.02-101-2014 вместо СП РК 2.02-101-2022 «Пожарная безопасность зданий и сооружений» — 8 раз;
   - СН РК 2.02-01-2014 и 2.02-01-2019 вместо СН РК 2.02-01-2023 — 7 раз;
   - СН РК 2.04-04-2013 и 2.04-21-2004 вместо СН РК 2.04-07-2022 «Тепловая защита зданий» — 7 раз;
   - СН РК 1.03-00-2011 вместо редакции 2022 года (ПОС) — 4 раза;
   - СН РК 1.02-03-2011 вместо СН РК 1.02-03-2022 — 1 раз.
3. **Байгабыл: 9 ссылок на заменённые нормы.** Те же СП РК 2.02-101-2014, СН РК 2.02-01-2014, СН РК 1.03-00-2011 и
   прежние номера документов 2013 года: СН РК 5.01-24-2013 — теперь СН РК 5.01-01-2013.
4. **Байгабыл: в графе 1 нет базового обозначения ни в одном альбоме.**
   - «-ОВ», «-ОВ.СО», «-АС», «ЭОМ.СО».
   - В шаблоне штампа в графе 1 — «Заказчик: ГУ "Управление строительства…"» и шифр марки среди этого текста.
   - В ОПЗ — заготовка «№– ПЗ».
5. **Тауыш: обозначения с ошибками записи.**
   - «ПОС» без базовой части на 42 листах.
   - «№2023-17 АР» на 17 листах — знак № и пробел вместо дефиса.
6. **Подписи.** В книге ПБ Тауыша у «ГИП» нет фамилии. В альбоме ВК Тауыша на 6 листах пуста строка «Н контроль».
7. **ИРД — всё обязательное на месте в обоих пакетах:** АПЗ, документ на землю, отчёты геологии и геодезии, ТУ,
   казахстанское содержание. «Проверить вручную» — там, где правило не может решить по тексту:
   - вместо решения об инвестировании — «Бюджетная программа»;
   - вместо задания на проектирование — медико-технологическое задание (МТЗ);
   - лицензия разработчика не найдена: может подаваться с заявкой; в Байгабыле есть только лицензия изыскателя;
   - расчёт стоимости ПИР не найден;
   - в Байгабыле не найден перечень цен по прайс-листам.

## Что поправили по ходу прогона

Первый прогон дал много шума. Каждый случай теперь закреплён фикстурой правила.

| Было | Стало |
|---|---|
| Все 35 штампов Тауыша одинаковы — значит, «норма» | наименование сверяется с заявленным на первых страницах ОПЗ или паспорта проекта; без ОПЗ — штампы между собой |
| «Инженерно-геологические условия» в ОПЗ засчитаны как отчёт изысканий | документ ищется сначала по имени файла, затем по заголовку страницы; листы с основной надписью проекта — не документы ИРД |
| Номер лицензии на титуле засчитан как лицензия; «Лицензия изыс.» — как лицензия разработчика | лицензия ищется только по имени файла; лицензия изыскателя — «похожий документ» |
| Заключение экспертизы в папке пакета давало «найденные» ТУ и задания | заключение экспертизы исключается из поиска: это результат, а не часть подачи |
| Текст из шрифта без кодировки («(cid:476)…») давал нарушения графы 1, стадии и наименования | значения с «(cid:» не судим |
| «№» в графе 1, отчёт геологов со своим штампом, искажённые роли («m конmр») давали нарушения | обрывки ячеек и документы без обозначения проекта не судим, подписи — только для узнаваемых ролей |
| Эскизный проект («ЭП_Строительство…») давал «другую стадию» | эскиз по имени файла — своя стадия законна, стадия пакета считается без него |
| 50 «нет в АГСК-1» на Тауыше — в основном разбор | скобка не часть номера; перенос строки внутри обозначения; «1.03.00-2011» и «2.02-052009»; «СН 2.02-02-2023» без «РК» |

## Чего правила пока не видят

- **ГОСТ.** В АГСК-1 их нет: 1 794 ссылки на ГОСТ и 312 на СТ РК в Тауыше не проверены. Правило честно пишет
  «проверить невозможно». Нужен свой индекс стандартов; открытый источник для РК ещё не найден.
- **Сметные нормы.** ЭСН РК и НДЦС РК (380 и 66 ссылок в Тауыше) сверяются по АГСК-5 — перечню нормативных
  документов по ценообразованию. Его можно скачать там же, где АГСК-1.
- **Листы без текстового слоя.** Сканы приложений ОПЗ и текст САПР в кривых — правило ИРД видит их и при
  ненайденном документе говорит «проверить вручную», а не «не найдено».
- **Точность не измерена.** Все находки двух пакетов просмотрены вручную по отчётам. Разметки «верно / ложная
  тревога» на большем числе пакетов пока нет — это H3 (≤ 5 ложных на 100 листов): нужно 20–30 пакетов.

## Как воспроизвести

```powershell
# полный пакет закупки (только PDF и zip): ~230 МБ на два пакета
python -I -X utf8 scripts/goszakup_kz_psd.py fetch var/real/goszakup_kz 17778737 17773093 --from-list var/real/goszakup_kz/_list.json --workers 4
# проверка; опись сохраняется и переиспользуется
uv run python -m zerocycle check var/real/goszakup_kz/17778737/files -j kz --scan var/check/tauysh.scan.json --md var/check/tauysh.md
uv run python -m zerocycle check var/real/goszakup_kz/17778737/files -j kz --from-scan var/check/tauysh.scan.json --json var/check/tauysh.json
# правила и карточки
uv run python -m zerocycle rules -j kz --cards docs/rules
```
