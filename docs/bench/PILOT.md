Агентские руки — Claude Code без интерфейса (`claude -p`, `bench/pilot.py`):
- модель — Opus 5.5, потолок $15 на прогон по ценам API, усилие — как у Claude Code по умолчанию;
- папка руки вне репозитория, со случайным именем, после прогона удаляется. В ней копия `package/`, у A1 — скилы,
  у B — MCP-сервер «Нулевого цикла» с корнем в этой папке;
- инструменты одни у всех: Bash, Read, Write, Edit, Glob, Grep, Skill. Веба нет. Python для PDF — системный, без кода
  «Нулевого цикла»;
- настройки пользователя не подхватываются (`--setting-sources project`);
- задача и схема ответа одни для всех рук (`bench/arms.py`);
- записываем:
  - токены, доллары, минуты, ходы и вызовы инструментов;
  - сбои;
  - доли пятичасового и недельного окон подписки;
  - пути вне папки руки — аудит изоляции.

Скилы A1 пишет отдельная сессия Claude Code (`zerocycle bench author`):
- только публичные источники из `bim-data`: ГОСТ Р 21.101-2020, ПП № 87 и № 145, приказ 783/пр и письма Минстроя о
  форматах, выгрузка реестра «Стройкомплекс.РФ»;
- без репозитория, правил и корпуса;
- для пилота — около часа и $15. Окончательные скилы — при заморозке.

Сопоставление — по протоколу, без знания правил движка:
- тот же документ и страница ±1;
- категория из допустимых проявлений дефекта;
- у дефектов отсутствия — раздел, обозначение или GUID в тексте находки.

«Нарушение» без дефекта — ложная тревога. Если оно легло на место из `notes` эталона, оно ещё и попадает в отдельную
разбивку по видам.

## Как запустить

После сброса пятичасового окна, из папки `zero-cycle`:

```powershell
# 1. скилы A1 — отдельная сессия по публичным источникам (~1 ч, потолок $15)
.venv\Scripts\python.exe -m zerocycle bench author var/bench/pilot/results --bim-data ../bim-data --budget 15

# 2. агентские руки: A0, A1, B — по 2 прогона на 3 пакетах, 3 одновременно; стоп при 90% окна подписки
.venv\Scripts\python.exe -m zerocycle bench run var/bench/pilot/results --corpus var/bench/pilot/corpus `
  --packages v1-dev-0222,v1-dev-0212,v1-dev-0224 --arms A0,A1,B --runs 2 --model claude-opus-5-5 `
  --budget 15 --skills var/bench/pilot/results/skills_A1 --parallel 3 --stop-at 0.9

# 3. оценка, таблица стоимости и прогноз полного прогона → var/bench/pilot/results/report.md
.venv\Scripts\python.exe -m zerocycle bench score var/bench/pilot/results --corpus var/bench/pilot/corpus
```

Остановленный прогон (лимит, сбой) продолжается той же командой `bench run`: готовые прогоны не повторяются. Корпус
пилота пересоздаётся командой `zerocycle gen var/bench/pilot/corpus --v1 --seed 222` (затем сиды 212 и 224).

## Что дальше

После прогонов:
1. Таблица стоимости и прогноз из `report.md` — сюда.
2. Бюджет утверждает владелец.
3. Заморозка протокола: модель, усилие, число прогонов, потолок на прогон, окончательные скилы A1.

Прогноз считается для четырёх сценариев:
- минимум: A1 и B, 11 пакетов, 3 прогона. 11 пакетов — это 80 дефектов в отложенной части при 7,5 дефекта на
  пакет;
- A0, A1 и B: 11 пакетов, 3 прогона;
- A0, A1 и B: 11 пакетов, 5 прогонов;
- A0, A1, B и B1: 20 пакетов, 5 прогонов.
