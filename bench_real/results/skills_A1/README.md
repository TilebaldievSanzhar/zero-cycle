# Скил нормоконтроля ПСД (Республика Казахстан)

`pd-expertise-check/` — скил Claude Code для проверки пакета проектно-сметной документации (PDF) на
формальные дефекты перед подачей в комплексную вневедомственную экспертизу. Установка: скопировать папку
`pd-expertise-check` в `.claude/skills/`.

## Что делает
| Блок | Скрипт | Источник требований |
|---|---|---|
| Инвентаризация PDF: текст по страницам, форматы листов, поля основной надписи (обозначение, стадия, Лист/Листов, Разраб./Пров./Н.контр./ГИП, даты, подписи как графические объекты), номера страниц, сканы | `scripts/extract_package.py` | ГОСТ 21.101-97 |
| Оформление: пустая стадия, разнобой стадий, пропуски/повторы листов, «Листов» ≠ факту, сквозная нумерация, нет «Содержания», подписи титула, форматы, объём тома | `scripts/check_titleblocks.py` | ГОСТ 21.101-97, пп. 4.1.3, 4.1.4, 5.27, 9.3–9.6, прил. Д |
| Комплектность: ИРД и документы по приложениям 2/3/4/4-1/5, ТУ по видам сетей, сметная документация, «Состав проекта» и «Содержание» против фактических томов | `scripts/inventory.py` + `references/completeness_checklist.json` | Приказ № 299, прил. 2, 3, 4, 4-1, 5 |
| Увязка томов: варианты наименования объекта, расхождения ТЭП и сметной стоимости | `scripts/cross_check.py` | ГОСТ 21.101-97, прил. Д б), в) |
| Ссылки на НД: действующие / заменённые («Взамен…») / нет в перечне / вне области АГСК-1 | `scripts/check_norm_refs.py` + индекс АГСК-1 | АГСК-1, июнь 2025 |
| Всё сразу | `scripts/run_all.py package ./_nk --stage РП` | |
| Рендер штампа/страницы в PNG для визуальной проверки | `scripts/render_page.py` | |

`SKILL.md` задаёт порядок работы, правила подтверждения кандидатов (визуально), выбор статуса
«нарушение» / «проверить вручную», допустимые основания и формат ответа (findings + summary).
Скрипты выдают только кандидатов; итоговые замечания агент подтверждает по файлам.

## Справочники (только из `sources/`)
- `gost21101_checklist.md` — выписка пунктов ГОСТ 21.101-97; `gost_21.101-97_full.txt` — полный текст.
- `completeness_checklist.json`, `prikaz299_prilozhenie_*.txt` — приложения 2, 3, 4, 4-1, 5 к Правилам (Приказ № 299).
- `agsk1_2025-06_index.json` (2037 записей, 311 со связями «взамен»), `agsk1_2025-06_text.txt`, `agsk1_notes.md` — АГСК-1.
  Индекс пересобирается командой `python scripts/build_agsk_index.py <AGSK-1.pdf> references/agsk1_2025-06_index.json`.

## Чего в источниках нет (скил об этом предупреждает)
- ГОСТ и СТ РК не входят в АГСК-1, поэтому их действие этим скилом не проверить.
- Сметные нормативы перечислены в АГСК-5, его в источниках нет.
- Нет текста СН РК 1.02-03-2022, поэтому обязательный перечень разделов РП не проверяется — только сверка с собственным «Составом проекта».
- Нет текста ГОСТ 2.301, поэтому форматы проверяются по известным размерам со статусом «проверить вручную».
- В тексте ГОСТ 21.101-97 нет рисунков форм основных надписей.

## Тестирование
`tests/make_test_package.py <dir>` генерирует тестовый пакет из 7 PDF (свой мини-PDF-писатель, без внешних шрифтов)
с заложенными дефектами (список — `EXPECTED` в файле). Прогон `run_all.py` на нём находит все заложенные дефекты:
- пропуск листа 3, «Листов» = 5 при 4 листах, нет фамилии и даты у Н.контр., у Пров. нет даты, сбой сквозной нумерации 5→7;
- пустая стадия, стадия «П» среди «РП», лист 400×297, другое наименование объекта («на 260 мест»);
- общая площадь 3850,0 / 3905,0 и сметная стоимость 2 405 000 / 2 450 000;
- 3 заменённые нормы, 1 норма не из перечня, ГОСТ/СТ РК/НДЦС вне области АГСК-1;
- в «Составе проекта» указан том КЖ, которого нет в пакете; в «Содержании» указан документ ПЗ.Р, которого нет в томе;
- отсутствующие ИРД; скан без текстового слоя.

Отдельно проверен лист, хранящийся как книжный с `/Rotate 90`.
