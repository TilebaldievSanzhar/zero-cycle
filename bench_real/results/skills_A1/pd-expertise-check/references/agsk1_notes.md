# АГСК-1 (по состоянию на июнь 2025) — как пользоваться при проверке ссылок

Файлы:
- `agsk1_2025-06_index.json` — индекс записей (шифр, нормализованный ключ, **страница PDF АГСК-1**, наименование,
  «утверждено», список заменённых документов `replaces`). Собран `scripts/build_agsk_index.py`.
- `agsk1_2025-06_text.txt` — сырой текст перечня с маркерами `=====PAGE n` (страница PDF). Для ручной проверки:
  `grep -n "1.02-03" agsk1_2025-06_text.txt`, затем найти ближайший сверху `=====PAGE`.

Ключевые факты из самого перечня (ссылаться можно):
- Перечень утверждён приказом председателя КДСиЖКХ МПС РК от 20.06.2025 № 97-НҚ (с. 4 PDF, Введение).
- **Не включены**: национальные стандарты РК (СТ РК, СТ РК ГОСТ Р, СТ РК EN, …) и межгосударственные стандарты
  (ГОСТ), а также отраслевые НТД других министерств (ПР РК, Р РК и т.п.) — Введение, с. 4–5 PDF.
  ⇒ действие ГОСТ/СТ РК по АГСК-1 проверить нельзя → «проверить вручную», в summary указать.
- Раздел 8 «Нормативные документы по ценообразованию и сметам» — «включены в АГСК-5» (с. 146 PDF).
  АГСК-5 в источниках нет ⇒ сметные нормативы (НДЦС РК, СН/СП РК 8.xx, ЕСН РК …) → «проверить вручную».
- Правила проведения комплексной вневедомственной экспертизы — Приказ МНЭ РК от 01.04.2015 № 299, действуют,
  изменения до приказа МПС РК от 01.10.2024 № 343 (с. 11 PDF).
- СН РК 1.02-03-2022 «Порядок разработки, согласования, утверждения и состав проектно-сметной документации на
  строительство» — **взамен СН РК 1.02-03-2011*** (с. 16 PDF). Текста СН РК 1.02-03-2022 в источниках нет —
  обязательный перечень разделов РП по нему проверить нельзя.

Классы `check_norm_refs.py`:
| cls | Что значит | Статус в findings |
|---|---|---|
| valid | шифр есть в перечне | не записывать |
| replaced | в перечне указано «Взамен <шифр>» или «Соответствует <шифр> … утративший силу» | **нарушение**: «ссылка на заменённый документ X; действует Y (АГСК-1, с. N)» |
| not_listed | шифр из области АГСК-1 (СН РК, СП РК, СНиП РК, МСН, МСП, РДС РК, НТП РК, ВСН, ВНТП, ОНТП, СНиП, МД РК) не найден ни в индексе, ни в сыром тексте | **нарушение** после ручного grep по 2–3 вариантам написания (номер без года, без «РК»): «документ отсутствует в перечне действующих (АГСК-1, июнь 2025)». Если сомневаетесь в распознавании — «проверить вручную» |
| raw_only | номер есть в тексте, но индекс не распознал | откройте страницу, решите сами |
| out_of_scope | ГОСТ, СТ РК, ТР ТС, ПУЭ, сметные нормативы | **не записывать как нарушение**; при желании — «проверить вручную» одним пунктом, и обязательно в summary |

Тонкости:
- Две формы связи в перечне: «Взамен X» (документ заменён новым) и «Соответствует X (приказ …, утративший силу)»
  (документ перенумерован, прежний шифр утратил силу). В замечании пишите дословно, какая формулировка стоит в
  АГСК-1 («взамен» или «соответствует … утративший силу»), со страницей PDF.
- Звёздочка (`2011*`) означает редакцию с изменениями; ключ сравнения без звёздочки.
- Год в шифре важен: `СН РК 2.02-01-2019` ≠ `СН РК 2.02-01-2023`. Поле `same_number_valid` подсказывает
  действующий документ с тем же номером.
- Опечатки латиницей (C/С, P/Р, K/К) нормализуются; в замечании цитируйте шифр **как в пакете** (`as_written`).
- Одна запись `replaced` = одно замечание на документ пакета: `page` — первая страница, где встречается ссылка,
  остальные страницы перечислите в тексте замечания. Если ссылка в нескольких документах — по замечанию на
  каждый документ.
