# Нулевой цикл (Zero Cycle)

Проверка пакета проектной документации перед экспертизой: комплектность, оформление, увязка документов
и ссылки на нормы. Каждая находка — с листом, рамкой на листе и пунктом нормы. Проектировщик выпускает,
система проверяет, ГИП решает.

Название двойное: «ноль кругов замечаний» и строительный нулевой цикл — работы ниже отметки 0.000,
фундамент, на котором стоит всё остальное. Рабочее; перед публичным использованием проверить на занятость.

- Продукт: [docs/product/STRATEGY.md](docs/product/STRATEGY.md), план: [docs/product/PLAN.md](docs/product/PLAN.md)
- Архитектура: [docs/architecture.md](docs/architecture.md), решения: [docs/adr/](docs/adr/)
- Бенчмарк против «Claude Code + MCP»: [docs/bench/PROTOCOL.md](docs/bench/PROTOCOL.md)
- Предметная область с нуля: [docs/domain/PRIMER.md](docs/domain/PRIMER.md)

## Статус

23.10.2026 — шаги 0.1–0.4: документы; модель пакета и разбор обозначений по ГОСТ Р 21.101-2020; опись пакета
(PDF, основные надписи форм 3–6, info.xml); генератор засеянных пакетов с 16 видами дефектов. Правил проверки
ещё нет — это шаги 0.5–0.7.

## Быстрый старт

```powershell
uv sync                                                   # Python 3.13, зависимости по uv.lock
uv run pytest                                             # тесты
uv run python -m zerocycle gen var/corpus --seed 1 --count 3   # засеянные пакеты: package/ и эталон рядом
uv run python -m zerocycle scan var/corpus/seed-0001/package   # опись: листы, основные надписи, обозначения, info.xml
uv run python -m zerocycle designation 2345-ИОС4.1.2-С 2345-AP # разбор обозначений
```

Команда `zerocycle` работает и напрямую (`uv run zerocycle …`), но на Windows со Smart App Control её
.exe-обёртку блокирует политика — тогда `python -m zerocycle`.
